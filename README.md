# ⚠️ Important Notes:

Currency codes: The project uses three-letter currency codes (ISO 4217), such as USD, EUR, GBP, and PKR. Some codes in the original country list may represent obsolete currencies and may not be supported by the selected API.

This project does **not use a live/updating API** — it uses a **fixed (static) exchange rate**. This means the rates are not fetched in real time from the internet; they are pre-set in the code. As a result, the exchange rate stays the same unless manually updated.

# 💱 Currency Converter

A simple and stylish **Currency Converter Web App** built with HTML, CSS, and JavaScript. Users can enter an amount and check the exchange rate between two currencies.

---

## ✨ Features

- 🔄 Convert between multiple currencies (From → To)
- 💵 Instantly view the exchange rate after entering an amount
- 🎨 Modern and clean UI design
- ⚡ Fast and lightweight — no backend/server setup required

---


---

## 🛠️ Tech Stack

- **HTML** – Structure
- **CSS** – Styling & Design
- **JavaScript** – Logic & Functionality

---

## 🚀 How to Run

1. Clone or download the repository
2. Open the `index.html` file in your browser
3. Enter an amount and select the "From" and "To" currencies
4. Click **Get Exchange Rate** to see the result
